# 斗地主 · 单机网页版

### 🎮 在线游玩：<https://wh12334.github.io/doudizhu/>

一个纯前端的三人斗地主小游戏：**1 名真人玩家 + 2 名电脑对手**。
角色形象取自参考图（一个地主、两个农民），背景音乐与所有牌型音效都由 Web Audio 实时合成，
不依赖任何外部音频文件、不依赖服务器，打开网页就能玩。

> 进游戏后点一下「开始游戏」：浏览器要求先有用户操作才允许播放声音。

- 真人玩家在下方（座位 0），两名电脑在右侧（小明）和左侧（老王）
- 谁叫分谁当地主，地主用「红袍财主」形象，两个农民用另外两张参考图
- 完全按照欢乐斗地主的牌型与倍数机制实现

## 玩法

1. 打开页面 → 点「开始游戏」
2. **叫分**：轮到你时可选 不叫 / 1分 / 2分 / 3分（只能叫比当前更高的分）
3. **出牌**：点击手牌选中（再点取消），点「出牌」；点「提示」自动帮你找能管上的牌；点「不出」表示要不起
4. 每回合有时间限制（叫分 15 秒、出牌 20 秒），超时会自动帮你出牌或不出

## 牌型（全部实现）

| 牌型 | 说明 |
| --- | --- |
| 单张 / 对子 / 三张 | 任意同点数 1 / 2 / 3 张 |
| 三带一 / 三带二 | 三张 + 1 张单牌 / 1 对 |
| 顺子 | 5 张以上连续单牌（3~A，不含 2 和王） |
| 连对 | 3 对以上连续对子（3~A） |
| 飞机 | 2 组以上连续三张，可带等量单牌或对子 |
| 四带二 | 四张 + 2 张单牌 / 2 对 |
| 炸弹 / 王炸 | 四张同点 / 双王，可压任意牌型，王炸最大 |

大小顺序：`3 < 4 < … < K < A < 2 < 小王 < 大王`，只有同牌型、同张数才能比较。

## 倍数与结算

- **底分** = 叫分（1~3 分）
- 每出一次 **炸弹 / 王炸**，倍数 ×2
- **春天**：农民一张都没出、地主走完 → 倍数 ×2
- **反春天**：地主只出了一手牌、农民走完 → 倍数 ×2
- 地主胜：地主 `+2×底分×倍数`，每个农民 `−底分×倍数`；农民胜则相反

## 声音

- **背景音乐**：3 段程序化生成的五声音阶循环 BGM
  - `lobby` 76 BPM（开始界面）、`game` 104 BPM（对局主音乐）、`tense` 132 BPM（炸弹/残局紧张段）
  - 古筝式拨弦（Karplus-Strong）+ 铺底 pad + 贝斯 + 木鱼节奏，无缝循环、切换有淡入淡出
- **牌型音效**：14 种牌型各有一套独立音效（顺子是上行琶音、连对是成对跳音、飞机是喷气上冲、炸弹是低频下坠+爆响、王炸更猛），另外还有叫分、不出、发牌、翻底牌、春天、胜负等音效
- **角色语音**：叫分、炸弹、只剩一张、胜利失败等会有中文播报（可在顶栏 🗣 关闭）
- 顶栏可分别开关 ♪ 音乐、🔊 音效、🗣 语音（浏览器要求先有一次点击才能出声，所以进入游戏后才会响）

## 测试

全部为 Node 脚本，无需安装任何依赖（本机无网络也能跑）：

```bash
node tests/rules.test.js     # 规则引擎：牌型识别/比大小/找牌，含与暴力枚举对拍 —— 258 项
node tests/game.test.js 300  # 300 局全自动对弈（含牌数守恒、分数守恒）—— 3.5 万项断言
node tests/audio.smoke.js    # 音频引擎：模拟 Web Audio，逐个音效与三段 BGM —— 114 项
node tests/static-check.js   # 静态接线：DOM id/资源/14 种牌型音效覆盖/手机适配 —— 74 项
node tests/ui.dom.test.js    # 用自制最小 DOM 真实执行 ui.js 打完数局 —— 56 项
```

`tests/dom-shim.js` 是一个约 400 行的最小 DOM 实现（选择器、事件冒泡、classList、innerHTML 解析），
用来在没有浏览器的环境里真实跑 ui.js，能抓出渲染与交互里的运行期错误。

## 目录结构

```
index.html            页面骨架（经典脚本，可直接 file:// 打开）
css/style.css         牌桌、扑克牌、座位、动画、手机/电脑自适应
js/cards.js           牌堆与点数工具
js/rules.js           牌型识别 / 大小比较 / 找牌 / 手牌拆分
js/ai.js              电脑决策（叫分、出牌、农民配合）
js/audio.js           Web Audio 音乐与音效合成引擎
js/game.js            对局状态机（发牌→叫分→出牌→结算），纯逻辑无 DOM
js/ui.js              渲染、交互、倒计时、动画
assets/avatars/       三个角色形象（透明背景 PNG，由参考图抠图生成）
tools/prepare-avatars.ps1   参考图 → 透明头像的处理脚本
tools/deploy-gh.js          推送到 GitHub 并开启 Pages（走 REST API）
tools/verify-ui.js          浏览器自动化验收脚本（Edge/Chrome + 手机双端）
tests/                规则、对局、音频、静态接线、UI 端到端测试
```

## 本地运行

直接双击 `index.html` 即可（无跨域、无模块依赖）。
如果想用本地服务器：

```bash
# 任选其一
python -m http.server 8080
npx serve .
# 然后浏览器打开 http://localhost:8080
```
