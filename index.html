玩法与牌型

基本流程

一副牌 54 张，每人 17 张，留 3 张底牌。叫分最高者成为地主，拿到底牌共 20 张，先出牌。先出完手牌的一方获胜。

牌型

单张 / 对子 / 三张任意同点数 1 / 2 / 3 张
三带一 / 三带二三张 + 1 张单牌 / 1 对
顺子5 张以上连续单牌（3~A，不含 2 和王）
连对3 对以上连续对子（3~A）
飞机2 组以上连续三张；可带等量单牌或对子
四带二四张 + 2 张单牌 / 2 对
炸弹 / 王炸四张同点 / 双王，可压任意牌型（王炸最大）

大小与倍数

大小顺序：3 < 4 < … < K < A < 2 < 小王 < 大王。只有同牌型、同张数才能比较。

每出一个炸弹或王炸，倍数 ×2；春天（农民一张没出、地主走完）倍数 ×2；反春天（地主只出了一手、农民走完）倍数 ×2。

地主胜：地主 +2×底分×倍数，每个农民 −底分×倍数；农民胜则相反。

操作

点击手牌选中/取消，「提示」会自动帮你找出可出的牌，「不出」表示要不起。每回合有时间限制，超时将自动帮你出牌或不出。
